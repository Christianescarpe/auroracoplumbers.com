Existing tankless unit

Tankless water heater repair in Aurora

An existing tankless heater that codes out, short-cycles, or gives up mid-shower is a repair problem. Replacing it with a new model, or going back to a tank, is a different permit conversation.

Which repair → Quote checklist →

What the visit should identify

Ask for the error code and what the manufacturer says it means. Ignition, vent blockage, scale, a failed sensor, and a bad flow sensor are not the same part. Descaling is maintenance. It is not proof the heat exchanger is sound. A company that sells a new unit without reading the code is skipping the page you are on.

Scale is a reason to ask what water the house actually gets. This guide does not claim Aurora's water is uniformly hard. No current city hardness table was used here. If someone recommends a softener or a filter as part of the repair, that recommendation needs a test of your water, not a metro slogan. Treatment equipment is a separate decision and is not written up as a product sales page here.

When repair should stop

Repeated exchanger failures, a discontinued model with no parts, or a vent that was never right are reasons to talk about a new installation or a return to a tank. Either change can alter gas, venting, and the inspection. Aurora's same-day inspection note is about replacement heaters and is not a guarantee. A repair that opens the gas train may still need a permit. Ask. Do not use internet steps to open the burner.

If the unit is gas and you smell gas, leave and call the gas utility. This website is not an emergency desk, and the quote checklist will not send your address anywhere.

What a repair quote should list

Ask for the model, the code, the part, and whether the heat exchanger is included or excluded. Ask whether the vent, the gas connector, and the condensate drain were inspected or only the circuit board. Ask who pulls a permit if the gas train is opened. A flush, a sensor, and a new heater are three prices. They should not share one line. If the house is in Castle Rock, a replacement tankless unit also needs the Town's manufacturer sheet and gas-load calculations. A repair that leaves the same unit in place does not automatically skip that question when the vent or the gas pipe changes. Write the exclusion down before you compare the number with a company that is selling a new heater.

Key Clarifications

Questions to settle first

Is descaling the same as a repair?

No. Flushing scale is maintenance. It can restore flow when the heat exchanger is coated and otherwise sound. It does not fix a cracked exchanger, a failed fan, or a vent that cannot breathe. Ask which fault the code names, and whether the part is available, before you approve a flush as the whole visit.

Should I replace the unit because Aurora has hard water?

Not from this guide. A citywide hardness number was not established here, and houses do not all see the same supply. Ask for a test if treatment is being sold with the repair. The repair itself should stand on the error code and the condition of this unit.

Does a parts repair need the same inspection as a new tankless heater?

Ask the Building Division. Aurora describes a same-day request for replacement heaters, with the right to come another day. A parts repair is not automatically that visit, and a new tankless install can need a fuller review. Get the permit answer for the work actually being done.

The company wants to convert me back to a tank. Which page is that?

Tank replacement, if you are leaving tankless, or a new tankless install if you are staying with tankless but changing the unit in a way that changes venting or gas. Repair stays on this page only while the heater you have is the one being fixed. Make them name which of the three the quote is.
